# 反 AI 味 · 移动端（anti-slop）

方法论来自 heydamir/unslop（CC BY 4.0, Damir Sokolovsky），按 375×812 移动端与本项目契约重写。
**这份文档一半在说「不要做什么」——因为 AI 生成的界面难看，几乎全是下面那 12 件事造成的。**

## 零、动手前先定方向（不定就别开始画）

规则只能保证「不难看」，要「好看」必须有方向。动手前先在脑子里回答这 5 项，后面所有取舍都服从它：

1. **产品**：一句话说清做什么、给谁用。
2. **性格**：2~3 个具体形容词（`冷静、精确、略带温度`）。**禁止用**「简洁、现代、高级、优雅、大气」——这些词等于没说。
3. **世界**：这个产品天然属于什么场所/材质？训练日志 → 铁片、汗水、计时器、磨损的胶皮；咖啡 → 烘焙色、纸袋、油脂。世界决定中性色的偏色方向（偏暖还是偏冷）。
4. **高光时刻**：1~2 处可以承载丰富色彩与细节的地方（一张大图表、一个当前训练卡、一组记录条）。其余地方一律安静。
5. **签名细节**：一个只有这个产品才有的、反复出现的小东西（训练页的「组间倒计时条」、咖啡页的「烘焙度圆点」）。**一个，不是五个。**

方向定完后做一次**模板测试**：把产品名换成别的产品，这套界面还成立吗？成立说明方向不够狠，重做。

## 一、先删掉这 12 样（命中任何一条，页面就废了）

1. **紫色/蓝色渐变**，任何色相渐变、渐变文字、渐变按钮、渐变图标底。
2. **发光**：彩色阴影、彩色光晕、霓虹描边、内容背后的径向色块。
3. **emoji 当图标或标签**（`🔥 热门`、`Welcome 👋`）。一个都不要。
4. **大写 + 宽字距的标签**（`NAVIGATION`、`POPULAR`）。全部 sentence case。
5. **感叹号**，尤其 `!!`。标题结尾不加句号。
6. **问候式标题**（`欢迎回来，阿志！`）。标题直接说这页是干什么的。
7. **炒作词**：超级、一键、无缝、赋能、解锁、魔法、革命性、极致、全新体验。
8. **无法核实的宣称**：`10 万+ 用户信赖`、`快 10 倍`。要写就写有出处的真实数字。
9. **假数据占位**：`[X]`、`123,456`、`Lorem ipsum`。数字要像真的（`100kg × 5`、`¥48`）。
10. **一切皆胶囊**：卡片、输入框、标签、按钮全是 `borderRadius: 999`。
11. **彩虹色图表 / 发光柱**：同一系列内多种色相、柱体带发光。
12. **无理由的动效**：呼吸光、漂浮、闪烁、每张卡从不同方向飞入、`hover` 时位移超过 2px。

## 二、颜色

- **一条中性阶 + 一个强调色**。背景、卡片、分隔线、文字全在中性阶上取，只有强调色可以跳出。
- 文字只分 **3 个角色**：主（`#111`）、次（`#5A5A5A`）、弱（`#9A9A9A`）。不要 8 种灰。
- **强调色只用在**：主操作按钮底、当前选中态、一个关键数字。全屏出现 3~5 次，不超过 8 次。
- 语义色只表意：涨用红 `#D33`、跌用绿 `#2A7`（中国习惯），错误用红。不要拿绿色当装饰。
- **分隔线 = 文字色的 8%**（如 `rgba(17,17,17,0.08)`），1px，不要用纯灰块。
- **渐变只在同一中性内**（`#2B2B2B → #1F1F1F`），绝不跨色相。能不用就不用。
- 主按钮：深色底 + 白字，或强调色底 + 白字，**不要渐变、不要阴影**。
- 本契约**没有阴影字段**，不要试图用描边+模糊模拟阴影。靠背景色差分层。

## 三、间距（4 的倍数，只用这几档）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

- 页面左右边距：**16**（375 宽下不要用 24，会显得空）。
- 卡片内边距：**16**；卡片之间：**12**。
- 组内间距 < 组间间距。同组内的项间距必须完全相同。
- 同一列表里所有行**同高、同间距**（行高 56~64，间距 8~12）。不要一行 52 一行 60。
- 图标与文字间距：**8**。
- 图标列、文字左边界、数字右边界各对齐成一条线。
- **禁止一次性数值**：`13`、`11`、`27`、`34` 这类随手打的数一个都不要。

## 四、字号与字重

字号阶梯只用：`34 / 24 / 20 / 17 / 15 / 13 / 11`（单位 px）

- 页面大标题：**34**，`fontWeight: 500`。
- 区块标题：**17**，500。正文：**15**，400。辅助：**13**，400。最小：**11**，400（**不要再小**）。
- **字重只用 400 和 500**，600 仅用于主按钮文字。**禁止 700/800/900**。
- **层级靠字号 + 颜色**，不要靠加粗。一个页面里 700 出现超过 2 次就是错的。
- 小字**禁止负字距**；`letterSpacing` 只在 34 的大标题上用 `-0.5`。
- 数字类内容（重量、金额、次数）**同一页只用一种格式**：要么全是整数，要么全是一位小数，不要 `100` 和 `102.5` 混着。

## 五、圆角（按尺寸分档，不要全 999）

- 按钮、输入框、小控件：**10**
- 卡片、列表容器：**14**
- 大面板、底部弹层：**20**
- 头像、圆形图标底：**999**（只有这一种可以用满）
- **嵌套时内圆角 = 外圆角 − 内边距**，最小 4。卡片 14 内边距 16 → 内部元素 0。

## 六、图标

- 只用契约里的 `icon` 名字，**不要写 `vectorD`**。
- 一个页面**一种尺寸**：`18`（列表行内）或 `16`（按钮内），不要混。
- 图标颜色跟随文字角色（次/弱），**不要给图标单独上色**。
- 不是每个标题都要配图标。**没有信息增量就不加**。

## 七、版式

- 一屏 = 一个明确的主任务。顶部大标题（34）说清这页干什么，下面直接给内容。
- **一个主操作**（黑底白字大按钮，宽 343、高 52、圆角 10），最多再加一个次要操作（纯文字）。
- 不要「堆叠居中」的模板感：标题、副标题、按钮全部居中 + 上下等距留白 = 一眼 AI。
  改成左对齐、信息密度不均的版式。
- 首屏不要有大片死空。内容撑不满就用真实条目补，不要靠加大间距撑。
- 列表行结构统一：`左图标/序号 + 主文字 + 次文字 + 右侧数值`，四栏对齐。
- 底部留出导航栏空间：tab 页 `layout.padding` 底部写 **64**，流程页写 0。

## 八、文案

- 标题说清「为谁做什么」，**换成别的产品就不成立**才算合格。
- 短标签（`搜索`），不要长句（`搜索任何内容...`）。
- 变化量必须带对比基准：`+12% 较上周`，不能只写 `+12%`。
- 按钮用动词：`开始训练`、`保存`，不要 `提交`、`确定`。
- 徽章能删就删，必须保留就做成安静的小字。

## 九、交付前自检（逐条打勾）

- [ ] 没有渐变、发光、彩色阴影、色块
- [ ] 界面上一个 emoji 都没有
- [ ] 所有间距都是 4 的倍数，且同类同尺寸间距完全相同
- [ ] 字重只有 400/500（600 只出现在主按钮）
- [ ] 只有一条中性阶 + 一个强调色，强调色出现 ≤8 次
- [ ] 圆角按档位走，没有「一切皆胶囊」
- [ ] 图标一种尺寸一种颜色
- [ ] 没有感叹号、没有问候式标题、没有炒作词、没有假数据
- [ ] 有一个主操作，其余都是次要的
