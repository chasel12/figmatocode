# 国际主义编辑排版（Swiss Editorial）

> 这份文档只回答一个问题：**界面应该长什么样**。它不改变输出契约，不改变产品结构。

## 设计原则

1. **信息优先，装饰为零。** 任何不承载信息的元素都是噪音。没有渐变、没有投影、没有玻璃拟态、没有装饰性插画。
2. **网格先于构图。** 先定左右边距和栏线，再往里填内容。所有元素左对齐到同一条基线上。
3. **层级靠字号、字重、留白，不靠颜色。** 一个页面里最多 3 个视觉重量级别。用颜色区分层级是廉价的做法。
4. **一种强调色，只给「当前状态」和「唯一关键动作」。** 其余全部是墨色与灰。
5. **线条代替容器。** 用 1px 发丝线分隔内容，不要用卡片背景、圆角、阴影去「框住」东西。

## 令牌

| 用途 | 值 |
|---|---|
| 页面底色 | `#F7F6F3`（纸白，不要用纯白） |
| 内容块底色 | `#FFFFFF`（仅用于需要浮起的一层，全页最多 1~2 处） |
| 主文字 | `#111111` |
| 次级文字 | `#6B6B6B` |
| 三级文字 / 单位 | `#A3A3A3` |
| 强调色 | `#E23D28`（高饱和红，只用于当前项与主按钮） |
| 发丝线 | `#E2E0DB` |
| 深色块（反白区域） | `#111111` 底 + `#F7F6F3` 字 |

**字号阶梯（严格只用这 5 档）**：`34` / `22` / `16` / `13` / `11`。

**间距**：全部是 4 的倍数。页面左右边距 `20`，区块之间 `32`，行内元素之间 `8`。

**圆角**：`0`。一处例外也没有。

**阴影**：不用。需要分层就用发丝线或底色差。

## 排版规则

- **大标题**：`34px`，字重 `700`，左对齐，字距收紧到 `-0.02em`，行高 `1.1`。可以占两行，不要为了塞进一行而缩小。
- **栏目标签**：`11px`，全大写，字距放宽到 `0.08em`，颜色 `#A3A3A3`。标签在标题**上方**，不在下方。
- **正文**：`16px`，行高 `1.6`，颜色 `#111111`，单行宽度不超过 `330`。
- **数字**：关键数据用 `34` 或 `40`，字重 `700`。数字与单位分开：数字大、单位 `11px` 灰、垂直对齐到数字底部。
- **编号**：列表项前面用两位编号（`01` `02` `03`），`11px`，`#A3A3A3`，与内容左对齐成独立一列。

## 组件规则

- **卡片**：无背景、无圆角、无阴影。用一条 `1px` 底边线与下一块分隔。卡片内部靠留白拉开，不靠 padding 框。
- **主按钮**：实心 `#111111` 底、`#F7F6F3` 字、圆角 `0`、高度 `48`、文案 `13px` 字重 `600`。整页只允许**一个**。
- **次按钮**：`1px` 描边 `#111111`、透明底、墨色字、圆角 `0`、高度 `40`。
- **强调按钮**：`#E23D28` 底、白字。只在「当前正在进行的动作」上出现，一屏最多一个。
- **列表行**：高度 `56~64`，行间 `1px` 线，左文右值，右侧值用 `13px` 灰。
- **标签 / 角标**：纯文字大写 + 字距，不要做成胶囊或圆角块。需要区分状态时用颜色，不要加底色。
- **分隔**：横向全宽 `1px` 线；纵向栏线只在表格类内容里出现。
- **进度表达**：用细线（`2px` 高）而非粗条；已完成段用墨色，未完成段用 `#E2E0DB`。不要用渐变或圆角进度条。

## 反白区块

允许整块 `#111111` 底 + 浅色字的区块，用来放「当前主任务」或「本周总结」。一个页面最多一块，高度不超过 `180`。反白块内部的强调色仍然是 `#E23D28`。

## 禁止清单

- 渐变（线性、径向、圆锥，一个都不要）
- 投影 / 阴影 / 发光
- 玻璃拟态、毛玻璃、半透明模糊
- 圆角大于 `2`
- 彩色图标（图标一律 `#111111` 或 `#6B6B6B`）
- emoji、装饰性图形、插画
- 超过两种彩色（强调红之外不许有第二种彩色）
- 卡片套卡片、卡片上加阴影
- 大段文字居中（只有单个大数字可以居中）
- 胶囊按钮、圆角标签、气泡提示

## 一屏的节奏

一个 375×812 的页面里，按这个顺序排：

1. 顶部：栏目标签（`11px` 大写）+ 大标题（`34px`），左右边距 `20`；
2. 一条全宽发丝线；
3. 主体内容：2~4 个区块，每块之间 `32`；
4. 唯一的那个主按钮或反白块；
5. 底部导航（只有 tab 页有）：**纸白底（同页面底色）** + 顶部 `1px` 发丝线，三项纯文字，当前项墨色 `600` + `2px` 下划线，其余 `#9A9A9A`。不要图标、不要胶囊、不要角标。

留白要**敢留**。内容没填满一屏时不要硬塞卡片，让下半部分空着，比塞满更像设计过。
