做一个记账小程序，共 6 个页面，页面名必须严格用这几个词，不要改名、不要加序号、不要加空格：

「概览」「明细」「记一笔」「预算」「统计」「我的」

品牌名「青柠账本」只出现在页面内容里，**不要写进页面名**（写成「青柠 概览」会让这一页进不了底部导航）。

整体基调：浅色、克制、信息密度高。白底、深灰文字，主色是墨绿，**只用在金额强调、主按钮、当前选中项这三处**，不要到处上色。数字要比正文更醒目（金额用大字号 + 粗体）。

## 各页内容

**概览**：顶部「11 月」月份选择 + 品牌名「青柠账本」；一张本月结余大卡片（本月支出大数字、本月收入、结余）；「本月预算」进度条（已用多少 / 总额）；「最近三笔」列表 5 行（分类、备注、金额、日期）；**一个文案为「记一笔」的主按钮**（放在页面中部或右下角，它是这一页最重要的入口）；底部导航栏。

**明细**：顶部月份 + 本月支出合计 + **一个文案为「统计」的文字入口**（放在顶部汇总区右侧）；按日期分组的流水，至少 3 个日期分组、每组 2~3 行（分类图标、分类名、备注、金额）；金额支出用深灰、收入用墨绿并带正号；底部导航栏。

**记一笔**：金额输入区（大号数字、¥ 符号）；支出 / 收入切换；分类九宫格至少 9 个（餐饮、交通、购物、居家、娱乐、医疗、学习、人情、其他）；备注输入框；日期；一个文案为「保存」的主按钮。**不要底部导航栏**（这是流程页）。

**预算**：本月总预算与已用进度（大号百分比）；分类预算列表**正好 6 行、分类互不重复**（餐饮 / 交通 / 购物 / 居家 / 娱乐 / 学习，每行：分类名、已用/预算、进度条、百分比）；超支的那一行用警示色并把文字标成「已超支」；一个文案为「调整预算」的按钮；**再放一个文案为「查看明细」的文字入口**（这一页必须有出去的入口）。**不要底部导航栏**。

**统计**：时间范围切换（本周 / 本月 / 本年）；一个分类占比区，至少 6 个分类（分类名、金额、百分比、一条占比条）；本月支出趋势说明两行（最高的一天、日均）；一个文案为「查看明细」的文字入口。**不要底部导航栏**。

**我的**：头像与昵称；账本数量、记账天数、连续记账三个数据；设置项列表至少 6 行（分类管理、预算设置、数据导出、账单提醒、主题、关于）；底部导航栏。

## 内容硬要求（不满足就是不合格）

1. **分类名、备注必须是具体的、像真的一样的**（「楼下面馆」「地铁 2 号线」「咖啡续命」「给妈妈买围巾」）。
   不要写「分类一」「备注」「项目 1」这种泛称，它们会被原样渲染到界面上。金额必须是具体数字（¥38.00、¥1,286.50），不要写「金额」。

2. **流水列表必须用 `repeat` 的命名式 `values` 生成**，每行的分类、备注、金额、日期都要不同：

   "repeat":{"count":9,"values":{"cat":[...],"note":[...],"amt":[...],"day":[...]}}

   子节点里分别写 `{{cat}}` / `{{note}}` / `{{amt}}` / `{{day}}`。
   **常见错误**：只把备注写成不同的，分类却全是「餐饮」、金额却全是「¥30.00」——这是不合格的。

3. **`repeat` 表达不了「其中一项特殊」**。要突出「超支的那一行」或「今天这一行」，就手写那一行，不要塞进 repeat。

4. **底部导航栏只在「概览」「明细」「我的」这 3 页出现**，含这三项（概览 / 明细 / 我的）。
   「记一笔」「预算」「统计」是流程页，**绝对不要**画底部导航栏 ——
   连一条空的分隔条、一排只有图标的占位都不要留。**这是本页最常见的错误，请逐页自查。**

5. **进度条用两层矩形**：底层浅灰轨道（宽度写满整行，实际约 300px），上层墨绿填充。
   填充宽度**必须与该行百分比成正比**：轨道内宽按 300px 算，86% 约 258px、58% 约 174px、30% 约 90px，
   超支的那条顶满 300px。**每行按自己的百分比给不同数值，不要都写同一个数** ——
   数据密度页里「六条一样长」是硬伤。
   分类列表可以用 `repeat` 写（省输出预算），此时逐条长度靠 `repeat.styles[i].width` 给
   （`"styles": [{"width":258},{"width":174},...]`，与 `values` 同 index 对齐）；不用 repeat 就逐条手写各自宽度。
   **「已超支」三个字只出现在百分比超过 100% 的那一行**，其余行不要标。
   分类图标不要用图片（IMAGE 只会渲染成占位色块），用图标或纯色圆底 + 文字。

6. 只输出契约里有的字段，不要自己加解释性键（如 note / comment / fix_note）。
